## On-Page Rules for Every Article
- One clear H1 with target keyword near start.
- Meta title length: 50-60 chars.
- Meta description length: 140-160 chars.
- First 120 words must include primary keyword naturally.
- Add 2-4 internal links to core service pages.
- Add FAQ block at the end when relevant.
- Add breadcrumb structured data.

## Measurement Targets (30 days)
- Indexed pages: +12 to +20
- Impressions: +40% to +80%
- Click-through rate: +0.8% to +2.0%
- Qualified leads via contact form: +20%+

## Weekly Review Routine
- Pull Search Console query report.
- Identify pages with high impressions and low CTR.
- Update title and description for those pages.
- Add one extra internal link from high-traffic pages to key service pages.
- Refresh one older article each week.
