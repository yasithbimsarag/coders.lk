# Google Search Console Setup Checklist (Execution)

Goal: Ensure Coders.lk is fully indexed, crawlable, and monitored for ranking growth.

## 1. Property Setup
- Open Google Search Console.
- Add property: https://coders.lk
- Verify ownership using DNS TXT record at domain provider.
- Confirm verification success.

## 2. Preferred Domain and Coverage
- Keep canonical domain as https://coders.lk
- Ensure www redirects to apex domain.
- Confirm no duplicate protocol/host variants indexed.

## 3. Submit Sitemap
- Go to Indexing > Sitemaps.
- Submit: https://coders.lk/sitemap.xml
- Verify status: Success.
- Re-submit sitemap after major content updates.

## 4. URL Inspection (Core URLs)
Inspect and request indexing for:
- https://coders.lk/
- https://coders.lk/services
- https://coders.lk/projects
- https://coders.lk/about
- https://coders.lk/contact
- All service detail URLs
- All project detail URLs

## 5. Coverage and Crawl Checks
- Indexing > Pages: check Excluded/Not Indexed reasons.
- Fix Soft 404, Redirect error, Crawl anomaly if found.
- Settings > Crawl stats: confirm regular Googlebot activity.

## 6. Performance Monitoring (Weekly)
- Search Results report filters:
  - Country: Sri Lanka
  - Query contains: web development, custom software, ecommerce, ui ux
- Track:
  - Total clicks
  - Total impressions
  - Average CTR
  - Average position

## 7. Query Optimization Loop
For pages with high impressions but low CTR:
- Improve title with stronger value proposition.
- Improve meta description with clearer intent match.
- Ensure keyword is present naturally.

## 8. Core Web Vitals
- Open Experience > Core Web Vitals.
- Fix mobile issues first.
- Focus on LCP, INP, CLS problem URLs.

## 9. Enhancements
- Validate breadcrumb rich results.
- Validate FAQ rich results where FAQ schema is used.
- Resolve warnings that affect eligibility.

## 10. Manual Actions and Security
- Check Security & Manual Actions weekly.
- Resolve any issues immediately.

## 11. Monthly KPI Dashboard
Track month-over-month:
- Index count
- Top 20 queries by clicks
- Top 20 landing pages by impressions
- Leads from organic sessions

## 12. Operating Cadence
- Weekly: 30-min Search Console review.
- Bi-weekly: update metadata on underperforming pages.
- Monthly: publish at least 4 new SEO pages/posts.
